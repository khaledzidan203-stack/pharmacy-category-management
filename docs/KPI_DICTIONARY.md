# KPI Dictionary — Pharmacy Category Management

This dictionary separates **implemented public-demo KPIs** from **extended design concepts** that are documented for future production-style implementations.

## Implemented SQL / Python KPIs

| KPI | Definition | Current implementation |
|---|---|---|
| Net Sales | Gross Sales − Discount Value | SQL + Python |
| Units Sold | Total sold quantity | SQL + Python |
| Gross Margin Value | Net Sales − Cost Value | SQL + Python |
| Gross Margin % | Gross Margin / Net Sales | SQL |
| Sales Contribution % | Entity Net Sales / relevant total | SQL + Python |
| Distribution % | Stores Selling / total demo branches | SQL |
| Days of Coverage | Stock Units / average daily units | SQL |
| Stock Units | Current snapshot quantity | SQL |
| Stock Cost | Current snapshot inventory cost | SQL |
| Near Expiry Units | Units with expiry ≤ snapshot date + 90 days | SQL |
| OOS Locations | Branch-SKU rows with zero stock | SQL |
| GMROI Proxy | Gross Margin / current Stock Cost | SQL |
| Promo Sales Mix % | Promo Net Sales / total SKU Net Sales | SQL |
| Supplier Fulfillment % | Received Qty / Ordered Qty | SQL + Python |
| Average Lead Time | Average receipt date − order date | SQL |
| Late PO Count | PO rows received after expected date | SQL |
| ABC Class | Cumulative sales-contribution segmentation | Python + SQL business query |

### Important implementation notes

- Zero denominators use `NULLIF` / explicit safe handling.
- GMROI is a **proxy** because the public model uses one current inventory-cost snapshot rather than average inventory over time.
- Near Expiry uses the SQL-demo 90-day horizon.
- Python and SQL use separate synthetic fixtures; identical KPI names do not imply row-for-row reconciliation between the two samples.

## Implemented assortment signals

| Signal | SQL-demo rule |
|---|---|
| Dead Stock | `units_6m = 0 AND stock_units > 0` |
| Overstock | `days_of_coverage >= 120` |
| Low Coverage | `days_of_coverage <= 14 AND units_6m > 0` |
| OOS Exposure | `oos_locations > 0 AND units_6m > 0` |
| Near Expiry | `near_expiry_units > 0` |

## Extended / future KPI catalog

The following are valid category-management concepts but are **not fully implemented as current executable public-demo measures**:

- Sales Growth %
- Target Achievement %
- Target Variance
- Inventory Turnover using average inventory
- true accounting GMROI using average inventory investment
- Supplier Dependency %
- Add Candidate logic
- promotion baseline uplift measures
- causal promotion impact
- customer-level behavior metrics
- competitor-price metrics

These should be implemented only when the required grain and historical data exist.

## Production governance

Thresholds must be business-owned and configurable. The current demo values are analytical assumptions, not universal category policy.
